# Excel GST Billing Invoice

## Overview
This is a beginner-level GST billing invoice created in Microsoft Excel.

## Features
- Customer Details
- Seller Details
- Product Table
- Quantity and Rate
- GST Calculation
- Subtotal and Grand Total
- Clean Printable Invoice

## Skills Used
- Microsoft Excel
- Cell Formatting
- Basic Formulas
- GST Billing
- Invoice Design

## Purpose
This project was created for learning and practicing Microsoft Excel.

**Note:** This is a sample invoice created for educational purposes only.
